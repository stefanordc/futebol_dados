1. Configurar a API

A FutPythonTrader é autorizada por padrão. Para outras APIs, configure o domínio HTTPS em ODDS_API_ALLOWED_HOSTS no .env. A chave pode ser guardada no Gerenciador de Credenciais do Windows, vinculada ao usuário local. Ela nunca é gravada no Supabase nem devolvida à interface.

◆

Proteção da chave de API

A chave é guardada no Gerenciador de Credenciais do Windows, depois de uma consulta válida. Não é salva no Supabase.

4. Selecionar colunas para inserir

Na primeira importação, selecionamos dados da partida e odds. Mercados de handicap asiático (AH) e europeu (EH) são excluídos, inclusive quando estavam selecionados anteriormente. Colunas Bookie, estatísticas e horário ficam desmarcadas. Depois, sua última seleção é reutilizada automaticamente. A origem de cada odd é preservada quando informada pela API.

Casas preferidas: Bet365 e Pinnacle (também Pinacle). O CSV informa uma casa por mercado; só é possível preferir essas casas quando a fonte realmente disponibiliza suas cotações. Outras odds não serão substituídas por preços inventados.

Lay simulado: cada odd numérica selecionada gera uma coluna lay_nome_da_odd. Usa um spread hipotético mínimo de um tick da escada da Betfair, sem preço executável nem liquidez verificada; comissão de 4,5% nas simulações.

5. Confirmar importação
A confirmação salva uma coluna SQL para cada dado selecionado. Partidas já existentes serão ignoradas, sem criar lotes duplicados. Nenhum registro será criado durante a prévia.
